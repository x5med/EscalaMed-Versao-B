# EscalaMED - versão B

Landing page alternativa do EscalaMED, construída a partir da referência aprovada e publicada como um projeto Next.js independente.

## Desenvolvimento

```bash
npm install
npm run dev
```

O arquivo `source/version-b.html` é a fonte visual. O comando `npm run generate:landing` produz `public/version-b.html` com GTM, consentimento, atribuição, dados legais, preço parcelado e WhatsApp.
